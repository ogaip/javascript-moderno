# JavaScript Moderno — Profundización y Desarrollo Web

Repositorio correspondiente a mi segunda etapa de aprendizaje de JavaScript.

Luego de completar una primera formación enfocada en los fundamentos del lenguaje, este proyecto tiene como objetivo profundizar en JavaScript moderno y adquirir los conocimientos necesarios para comenzar a desarrollar aplicaciones web y posteriormente avanzar hacia React.

## 🎯 Objetivo

Profundizar mis conocimientos de JavaScript trabajando principalmente con:

* Funciones modernas
* Métodos avanzados de arrays
* Scope y funcionamiento interno de JavaScript
* ES6+
* Destructuring
* Spread y Rest
* DOM
* Eventos
* Programación orientada a objetos
* Promesas
* Async / Await
* Fetch API
* Consumo de APIs
* Manejo de errores
* ES Modules

* 🎥 Contenido seleccionado: ~17 horas
* 💻 Estudio + práctica estimada: 25–30 horas
