# JavaScript Moderno

Repositorio correspondiente a mi segunda etapa de aprendizaje de **JavaScript**.

Después de completar una primera formación enfocada en los fundamentos del lenguaje, este repositorio está orientado a profundizar en conceptos de **JavaScript moderno**, manipulación del DOM, eventos, métodos avanzados de arrays, asincronía, consumo de APIs y otros conocimientos necesarios antes de avanzar a **React**.

## 🎯 Objetivo

Consolidar y ampliar mis conocimientos de JavaScript mediante teoría, práctica y ejercicios, enfocándome especialmente en:

* Arrow Functions
* Objetos y destructuring
* Optional Chaining
* DOM
* Eventos
* Métodos avanzados de arrays
* Spread Syntax
* Formularios
* Promesas
* Async / Await
* Fetch API
* JSON
* Manejo de errores
* Módulos ES
* Programación Orientada a Objetos
* Consumo de APIs
